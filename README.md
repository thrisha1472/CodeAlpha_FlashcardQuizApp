# CodeAlpha Flashcard Quiz App

A responsive flashcard study app built with HTML, CSS, and vanilla JavaScript for CodeAlpha App Development Internship — Task 1.

## Features
- Reveal question answers and switch back to the question
- Navigate with Previous / Next and card progress dots
- Add, edit, and delete flashcards
- Organize cards with optional categories
- Automatically saves cards in the browser using localStorage
- Responsive design for desktop and mobile
- Includes five sample study cards

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add or edit cards; your changes are stored in that browser.

No build tools or dependencies are required. Google Fonts is optional; a local sans-serif fallback is included.

## Files
- `index.html` — page structure
- `style.css` — layout and responsive styling
- `script.js` — flashcard interactions and local storage

## Notes
Flashcards are stored in the browser where the app is opened. They are not synced across devices or browsers.
